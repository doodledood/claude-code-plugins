# claude-code-plugins

A marketplace of Claude Code plugins with agents, skills, and hooks.

## Language

**Mirror**:
A symlink pointing to a repository-local skill's canonical directory.
_Avoid_: Sync, copy.

## Relationships

Manifest Dev workflow skills come from the installed Manifest Dev plugins. Repository-local skills remain in this repository and can have mirrors for discovery by another harness.
